## Guidelines

- **Format:** PNG
- **Content:** capture the widget as it renders inside the Otto chat panel (the card only, or the card in its conversational context)
- **Naming:** use the exact filenames above — the README image links depend on them
- **Recommended width:** ~800–1200px for crisp rendering on the README
